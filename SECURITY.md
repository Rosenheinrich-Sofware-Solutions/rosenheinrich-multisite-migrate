# Security Policy

This policy covers **Rosenheinrich Multisite Migrate** (Free, on WordPress.org) and **Multisite Migrate Plus & Pro**, including the license server and customer portal at multisitemigrate.rosenheinrich.com.

## Reporting a vulnerability

Report security issues to **phillip@rosenheinrich.com**; we aim to respond within 72 hours.

- Please **do not** open a public GitHub issue or WordPress.org support topic for security problems.
- Include the plugin edition and version, your WordPress/PHP versions, steps to reproduce and the impact you observed. A proof of concept helps.
- Machine-readable contact: https://multisitemigrate.rosenheinrich.com/.well-known/security.txt

## What happens next

1. We confirm receipt within 72 hours.
2. We investigate, keep you updated, and agree on a disclosure date with you (coordinated disclosure; please allow up to 90 days for a fix).
3. Fixes ship in the latest release of Free and Plus/Pro. We credit reporters in the changelog if they wish.

## Supported versions

Only the latest released version of each edition receives security fixes. Please update before reporting.

## EU Cyber Resilience Act

Where Art. 14 of Regulation (EU) 2024/2847 applies, actively exploited vulnerabilities in the product and severe incidents having an impact on its security are notified simultaneously to the CSIRT designated as coordinator and to ENISA via the ENISA Single Reporting Platform (Art. 16), and affected users are informed as required.
